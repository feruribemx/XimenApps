TABLAS - VERSIÓN 4

Esta carpeta trae todo lo que necesita la app:
  index.html   -> la app completa (diseño y código en un solo archivo)
  icon.png     -> el ícono para la pantalla de inicio
  vercel.json  -> hace que el iPad y los celulares siempre carguen la versión más nueva

CÓMO SUBIRLA A GITHUB
1. Abre tu repositorio tablas-ximena en github.com
2. Add file -> Upload files
3. Abre esta carpeta, selecciona los 4 archivos (no la carpeta) y arrástralos
4. Commit changes
Vercel la publica solo en menos de un minuto.
